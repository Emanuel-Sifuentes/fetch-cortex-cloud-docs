# Ingest third-party data sources
Cortex Cloud Application Security supports the following third party ingestions:

-   Semgrep
    
-   Snyk
    
-   SonarQube
    
-   Veracode
    
-   Generic 3rd Party AppSec Collector
    

**Note**

Only onboarded and scanned repositories can be mapped.
